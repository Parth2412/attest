## 3. Justfile targets

```make
default: check

    uv run ruff check .

    uv run ruff check --fix .
    uv run ruff format .

    uv run python scripts/run_mypy.py

    uv run lint-imports

    uv run pytest

    uv run python scripts/run_test_group.py vectors F-01 F-02

    uv run python scripts/run_test_group.py adversarial F-08

    @echo "not yet implemented — schema generation belongs to BRD-F01" >&2
    @exit 2

    git diff --exit-code spec/schemas/

    uv run python scripts/check_banned_language.py

    uv run python scripts/check_traceability.py

security:
    uv run bandit -r packages --exclude "*/tests/*" -c pyproject.toml
    uv run pip-audit

release-gate: check vectors adversarial schema-check banned trace security
```

## 4. Branch and commit conventions

| Concern | Convention |
|---|---|
| Branches | `feat/F-06-sigstore-signing`, `fix/…`, `docs/…`, `spec/…` — feature branches name their `F-` id |
| Commits | Conventional Commits; body **MUST** reference the `REQ-` ids implemented |
| PRs | One feature or one coherent slice; PR description lists `REQ-` and `AC-` ids covered |
| Merge | Squash merge (the ChangeSet Digest design accommodates this — `ADR-002`) |

Commit trailer convention for this repository's own AI use:

```
X-Attest-Claim: agent=claude-code; model=anthropic/<model>; session=<id>
```

Dogfood from commit one. It is the best possible proof the tool works.

## 6. Working with an AI coding agent on this repository

The intended loop, designed to keep the agent grounded:

1. **Scope one BRD per session.** Give the agent `AGENTS.md`, `GLOSS-001`, `SPEC-001`, and the
   single `BRD-Fxx`. Not the whole document set — irrelevant context invites invention.
2. **Require the plan first.** Ask for a plan citing `REQ-` ids before any code.
3. **Verify library APIs before use.** The agent must run the code or read installed source, not
   recall from training. `AGENTS.md §4`.
4. **Tests before or alongside implementation**, each referencing its `AC-` id.
5. **Run `just check` every iteration.** Type errors and import violations are the early warning
   system for hallucinated structure.
6. **Human review of every requirement mapping.** Confirm each `REQ-` is genuinely implemented,
   not merely name-dropped in a comment.
7. **Never let the agent regenerate a failing test vector.** `QA-001 §4`.

### 6.1 Session hygiene

- One feature per session. Long sessions drift.
- If the agent proposes a design change, stop and write an ADR rather than accepting it inline.
- If the agent cannot find an API, the answer is to read the installed package, never to invent
  a plausible call.

## 7. Onboarding a new contributor (or a fresh agent session)

Reading order:

1. `MPD-001` §1–3 — what this is and is not
2. `GLOSS-001` — vocabulary
3. `SPEC-001` — the format
4. `ARCH-001` §2, §6 — boundaries and trust model
5. `AGENTS.md`
6. The single `BRD-Fxx` being worked on

Nothing else is required to start. Anything more is context that invites drift.
