# Normative test vectors

This directory is reserved for the plain-file conformance vectors required by SPEC-001 §12.
At bootstrap, each named directory contains only `.gitkeep`; those placeholders are not vectors.
BRD-F01 creates canonicalisation, Statement, and CSD-1 algorithm vectors. BRD-F02 adds real-git
extraction coverage. Expected results must never be regenerated merely to satisfy a failing test.
